Click Assist - mod de Geode v5.11.1

Compilar (necesitas Geode CLI, CMake, y Visual Studio con C++ en Windows):
  geode sdk update
  geode sdk install-binaries
  geode build

O sube la carpeta a GitHub y ejecuta el workflow "Build"; el .geode sale en Artifacts.

Antes de publicar cambia "tunombre" en mod.json por tu nombre/usuario.
